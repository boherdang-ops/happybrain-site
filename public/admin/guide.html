어디서 수정하나요?

  • 첫 화면: 큰 제목·소개, 사업과 서비스, 교육 요약, 진행 방법, 버튼과 자료 연결
  • 법인 소개: 대표 인사말·서명과 화면 제목. 기관 소개·사업 영역은 공통 정보에서 수정
  • 사업 문의: 안내 문구·Q&A·질문하기 소개와 버튼. 이메일·전화는 공통 정보에서 수정
  • 인사이트·소식 소개: 각 페이지 맨 위 제목과 설명
  • 공통 정보: 법인 정보·연락처·사업 영역·메뉴·로고·푸터·알림 배너
  • 콘텐츠: 공지·소식, 인사이트, 교육 자료실, 영상, 기존 행정지원앱

저장·게시

기존과 같은 계정으로 로그인해 수정 후 저장·게시합니다. 게시 처리 후 공개 페이지를 새로 열어 확인하세요. 초안으로 설정한 게시글은 공개되지 않습니다.

교육 안내·Learning Hub·실무지원의 상세 콘텐츠는 각 사이트에서 관리합니다. 이 CMS에서는 홈페이지의 소개와 연결 주소만 관리합니다.

구버전 보관함

이전 교육과정·책·개인 소개·채널을 한곳에서 관리합니다. 원본 자료와 기존 주소는 보존했습니다. 이곳의 수정은 현재 법인 홈페이지 소개에 반영되지 않지만, 기존 교육과정·책 페이지에는 반영될 수 있습니다.
